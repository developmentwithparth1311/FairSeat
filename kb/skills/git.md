# Git

## What it is
Git tracks file changes over time and supports collaboration through commits and branches.

## Why employers ask for it
Interns may review changes, organize analysis scripts, and collaborate without overwriting work.

## How to get started (beginner path)
1. Learn status, add, commit, and log.
2. Practice branches and merging in a small folder.
3. Write concise commit messages and resolve a conflict.

## Practice ideas
- Track a portfolio project with meaningful commits.
- Collaborate on a README using separate branches.
