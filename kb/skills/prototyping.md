# Prototyping

## What it is
Prototyping creates an early model so people can explore an idea and give feedback.

## Why employers ask for it
Interns may connect screens, simulate interactions, and record user friction.

## How to get started (beginner path)
1. Start with a user goal and simple screens.
2. Link screens to represent a task flow.
3. Observe a peer and note friction points.

## Practice ideas
- Prototype a campus service request flow.
- Test two navigation labels and summarize observations.
