# Aws

## What it is
Amazon Web Services is a cloud platform providing computing, storage, databases, and other hosted services.

## Why employers ask for it
Interns may deploy small applications, store files, and document how cloud components work together.

## How to get started (beginner path)
1. Learn basic cloud concepts and shared responsibility.
2. Study core compute, storage, and networking services.
3. Build a tiny test environment and remove it after practice.

## Practice ideas
- Deploy a static portfolio page.
- Draw a simple cloud architecture for a web application.
