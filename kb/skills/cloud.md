# Cloud

## What it is
Cloud computing provides hosted computing resources without requiring each team to run physical servers.

## Why employers ask for it
Interns may document resources, test deployments, and learn basic access and cost controls.

## How to get started (beginner path)
1. Learn compute, storage, and networking concepts.
2. Compare infrastructure, platform, and software services.
3. Deploy a small practice project and document it.

## Practice ideas
- Draw a cloud architecture for a simple website.
- Make a checklist for shutting down test resources.
