# Machine Learning

## What it is
Machine learning uses data examples to build models that predict outcomes or group similar items.

## Why employers ask for it
Interns may prepare data, evaluate model results, and communicate limitations.

## How to get started (beginner path)
1. Review Python and descriptive statistics.
2. Learn training data, test data, and overfitting.
3. Train a small model and compare it with a baseline.

## Practice ideas
- Classify a small dataset and document its limits.
- Compare two models on the same held-out data.
