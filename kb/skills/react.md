# React

## What it is
React is a JavaScript library for building user interfaces from reusable components.

## Why employers ask for it
Interns may build interface pieces, connect data to views, and fix interaction issues.

## How to get started (beginner path)
1. Learn JavaScript, HTML, and CSS basics.
2. Build small components with props and state.
3. Split a page into reusable parts.

## Practice ideas
- Build a searchable internship resource list.
- Create a form with validation and clear feedback.
