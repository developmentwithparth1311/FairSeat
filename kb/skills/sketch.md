# Sketch

## What it is
Sketch is a digital design tool for interface layouts and reusable visual components.

## Why employers ask for it
Interns may organize screens, maintain symbols, and prepare design files.

## How to get started (beginner path)
1. Learn artboards, shapes, text, and alignment.
2. Create reusable components for an interface.
3. Share a prototype and collect focused feedback.

## Practice ideas
- Design a three-screen mobile information flow.
- Create reusable navigation components.
