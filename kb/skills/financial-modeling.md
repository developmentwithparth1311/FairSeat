# Financial Modeling

## What it is
Financial modeling represents financial assumptions and outcomes in a structured, inspectable spreadsheet.

## Why employers ask for it
Interns may update assumptions, check formulas, and compare scenarios for planning.

## How to get started (beginner path)
1. Learn spreadsheet formulas and statement basics.
2. Separate inputs from calculations and outputs.
3. Test how one assumption changes a forecast.

## Practice ideas
- Create a fictional shop's three-year forecast.
- Add lower, base, and higher cases to a budget model.
