# Linux

## What it is
Linux is an open-source operating system used on computers, servers, and cloud systems.

## Why employers ask for it
Interns may inspect files, run tools, and understand basic server environments.

## How to get started (beginner path)
1. Learn directories and safe navigation commands.
2. Practice permissions in a test folder.
3. Run a small program and read its output.

## Practice ideas
- Organize and search sample logs.
- Write a script that summarizes file counts.
